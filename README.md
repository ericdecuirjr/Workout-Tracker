# Workout Tracker

Minimalist mobile-first workout logging web app. Tracks exercises, sets, weight, reps, rest timers, history, and progress charts. Includes exercise demonstration search links. Data stays in your browser's local storage; export CSV for backups.

## Run
Upload the **individual files** (not the ZIP itself) to the root of a GitHub repository. To use on a Galaxy, host these files on an HTTPS static website and open the site in Chrome. Use Chrome menu > Add to Home screen to install when supported. GitHub Pages availability for private repositories depends on your GitHub plan; alternatively use another static host. The ZIP is source code, **not an Android APK**.

No build tools required. No account or cloud sync. Clearing browser data can delete saved workouts.
