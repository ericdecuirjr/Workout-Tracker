Workout Tracker Phase 2 — GitHub Pages update

1. Back up your existing workouts from History > Backup JSON (if available), or export CSV from Phase 1.
2. In your GitHub repository, upload ALL files from this ZIP to the repository ROOT, replacing index.html, app.js, and style.css. Do not upload the ZIP itself.
3. Wait for GitHub Pages to deploy, then reopen your existing app link. If the old version appears, refresh the page or close and reopen the installed shortcut.
4. Phase 2 uses the same localStorage key (workout-tracker-v1), so existing logs should remain on the same device/browser/origin. Data may not carry across browsers or if site data was cleared.
5. Exercise demonstration links open YouTube search results; videos require internet.

Includes: five-day plan, expanded exercise list, set-type notes, progress charts, workout history, timer, CSV export, JSON backup and restore.
